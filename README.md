# java-string-tools

A simple Java project for performing common string operations using user input.

## Features
- Find index of a word in a text
- Replace words in a text
- Extract substring from a text
- Compare two strings

## Example
Enter a text: Hello World  
Enter a word to find: World  
Index: 6  

Enter word to replace: World  
Enter replacement: Java  
Replaced text: Hello Java  

Enter start index: 0  
Enter end index: 5  
Substring: Hello  

Enter another text to compare: Hello  
Are equal: false  

## Technologies
- Java
- IntelliJ IDEA

## Concepts Practiced
- String methods (indexOf, replace, substring, equals)
- Methods and return types
- User input (Scanner)
